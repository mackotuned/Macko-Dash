MACKODASH SQUARELINE CUSTOMER INSTRUCTIONS
Object Names, Live Values, Bars, Arcs, and Theme Export
Version 1 - SquareLine Studio / LVGL 8.4 - Recommended canvas 1024 x 600


WHAT THIS SHEET IS FOR
======================
MackoDash uses an object's SquareLine name to decide which live vehicle value
controls it. You design the appearance. MackoDash supplies the live data.

Use the exact names in this sheet whenever possible. They are ready to copy
and paste.


QUICK START
===========
1. Create one 1024 x 600 screen in SquareLine Studio.
2. Set the project/export LVGL version to 8.4 or LVGL 8.x.
3. Add Labels for numbers and text values.
4. Add Bars or Arcs only for the supported gauges listed below.
5. Select each live object and enter its MackoDash name in SquareLine's
   object Name field.
6. Add a Button named dash_settings_button.
7. Export the complete C project from SquareLine.
8. ZIP the entire exported folder.
9. Open MackoDash Theme Builder and select the SquareLine ZIP.
10. Build the .mdtheme.zip package, then use Copy to SD Card.

SquareLine normally adds ui_ to generated variable names. That is okay.
For example, an object named dash_rpm_value may export as ui_dash_rpm_value.
MackoDash accepts both.

IMPORTANT GAUGE LIMIT
=====================
The following currently work as Labels only. Do not create live Bars or Arcs
for them because those gauge names are not supported by the customer runtime:

  gear, AFR, timing, manifold/boost, battery voltage,
  injector duty, knock retard, and odometer

For example, dash_afr_value is supported, but dash_afr_bar and dash_afr_arc
are not supported.

REQUIRED SETTINGS BUTTON
========================
Every customer theme should contain one SquareLine Button named:

  dash_settings_button

MackoDash connects this Button to the dashboard Settings menu. The button may
use any supported position, size, color, and text. Keep it easy to reach.


USING THE SAME LIVE VALUE MORE THAN ONCE
========================================
Add _2 through _9 when a value appears more than once. This works with Labels,
Bars, Arcs, unit Labels, and the settings Button.

Examples:

  dash_rpm_value
  dash_rpm_value_2
  dash_rpm_value_3

  dash_rpm_bar
  dash_rpm_bar_2

  dash_ect_unit
  dash_ect_unit_2

Never give two SquareLine objects the exact same name.


NAMING RULES AND TYPO HELP
==========================
- Names are not case-sensitive.
- Spaces and hyphens are treated like underscores.
- SquareLine's automatic ui_ prefix is ignored.
- A unique one-letter typo, missing letter, extra letter, or swapped pair is
  usually corrected automatically.
- If a typo could mean two different values, MackoDash refuses to guess.
- Canonical names from this sheet are strongly recommended for customer work.

These all resolve to the RPM value Label:

  dash_rpm_value
  DASH RPM VALUE
  dash-rpm-value
  ui_dash_rpm_value
  dash_rpm_vlaue

SQUARELINE DESIGN RULES
=======================
- Use one dashboard screen.
- A 1024 x 600 landscape canvas gives the best result.
- Keep important objects fully inside the screen.
- Use Labels, Bars, Arcs, Images, and Buttons.
- Built-in exact fonts are Montserrat 12, 14, 28, and 44.
- Custom fonts require an exact supported font workflow. Theme Builder strict
  mode stops instead of silently changing an unsupported font.
- Size live Labels for their longest possible value.
- Decorative objects must not start with dash_.
- Do not add custom C code or scripts to a customer theme.
- Do not create multiple dashboard screens.

Smaller landscape canvases are supported and are uniformly scaled and centered
without stretching. A 1024 x 600 project is still strongly recommended because
it provides the most predictable text size and placement.


WARNING LIGHTS AND ADVANCED INDICATORS
======================================
The firmware recognizes advanced names such as dash_cel_indicator,
dash_vtec_indicator, dash_shift_indicator, dash_oil_indicator, and
dash_knock_indicator. These are reserved for advanced/manual theme packages.
The current customer Theme Builder does not import generic SquareLine indicator
objects, so do not rely on these names in a customer SquareLine project yet.


EXPORT AND BUILD
================
1. Save the SquareLine project.
2. Export the complete C project, not a screenshot or preview image.
3. ZIP the entire exported project folder with its screens, images, and project
   information intact.
4. Open MackoDashThemeBuilder.exe.
5. Select the SquareLine export ZIP.
6. Enter the theme display name and a unique lowercase Theme ID.
7. Leave strict validation enabled for customer packages.
8. Select Build Theme Package.
9. Select Copy to SD Card and choose the SD card drive.
10. Insert the SD card into MackoDash and reboot.

The finished file is placed in:

  /MACKODASH/THEMES

MackoDash supports up to 30 SD card themes.
