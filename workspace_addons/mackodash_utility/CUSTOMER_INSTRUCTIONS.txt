MACKODASH UTILITY
=================

Keep all files in this folder together:
  MackoDashUtility.exe
  mackodash.bin
  CUSTOMER_INSTRUCTIONS.txt
  MackoDash_SquareLine_Customer_Instructions.txt

THEME BUILDER TAB
-----------------
1. Export the complete one-screen project from SquareLine Studio.
2. ZIP the exported folder.
3. Open MackoDash Utility and select the Theme Builder tab.
4. Choose the SquareLine ZIP and enter the theme name and ID.
5. Select Build Theme, then Copy to SD Card.

See MackoDash_SquareLine_Customer_Instructions.txt for all supported object
names, Bars, Arcs, values, ranges, and design rules.

FIRMWARE UPDATE TAB
-------------------
1. Connect MackoDash to the Windows PC with its update USB cable.
2. Keep the dashboard powered for the entire update.
3. Open the Firmware Update tab.
4. Confirm that mackodash.bin shows as Validated.
5. Confirm the dashboard COM port.
6. Select Flash ESP32-P4 Update and wait for verification to finish.

The update writes only the ESP32-P4 dashboard application. It preserves
settings, odometer data, SD-card themes, SPIFFS, and ESP32-C6 firmware.

Do not unplug USB or power during an update. If the port is busy, close serial
monitors and other flashing programs, then retry.
