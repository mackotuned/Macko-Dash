MACKODASH UTILITY
=================
Version 2.1

Keep all files in this folder together:
  MackoDashUtility.exe
  MackoDash-Firmware.zip
  CUSTOMER_INSTRUCTIONS.txt
  MackoDash_SquareLine_Customer_Instructions.txt

THEME STUDIO
------------
1. Open MackoDash Utility and choose Theme Studio.
2. Add labels, gauges, images, buttons, and other supported controls to the
  1024 x 600 canvas, then assign live ECU bindings in the inspector.
3. Use typical and longest-value previews to check fit and gauge movement.
4. Save the editable project, then export a dashboard-ready .mdtheme.zip.
5. Copy the package to an SD card or select Send Theme to install it over USB.

SQUARELINE THEME BUILDER
------------------------
1. Export the complete one-screen project from SquareLine Studio.
2. ZIP the exported folder.
3. Open MackoDash Utility and choose Build a Theme.
4. Choose the SquareLine ZIP and enter the theme name and ID.
5. Select Build Theme, then Preview Theme. Check both value modes and fix any
  reported clipping, unsupported controls, or missing Settings/REC buttons.
6. Select Copy to SD Card, or connect the dashboard and select Send over USB.
7. For USB installation, choose the dashboard COM port and keep power connected
  while the package transfers. The dashboard restarts after installation.

See MackoDash_SquareLine_Customer_Instructions.txt for all supported object
names, Bars, Arcs, values, ranges, and design rules.

BOOT LOGO
---------
1. Open MackoDash Utility and choose Boot Logo.
2. Select a PNG or JPEG, choose Fit or Fill, and preview the 1024 x 600 result.
3. Export the .mdlogo file or connect the dashboard and select Send over USB.
4. Select or delete installed logos under Settings > Display > Boot Logo.

The built-in logo always remains available as a fallback.

VIEW DRIVING LOGS
-----------------
1. Open MackoDash Utility and choose View Driving Logs.
2. Select Open CSV for one log, Find on SD Card for removable storage, or
  Download from Dashboard to use the connected USB update cable.
3. For USB download, choose the dashboard COM port, select Find Logs, then
  choose a recording and select Download and Open.
4. Drag the time-scale control and use the bottom scrollbar to move through
  the recording horizontally.
5. Hover over any point to see the exact values from that recorded sample.
6. Open Select Channels to choose a tuning preset or build a Custom view.

The AFR / Timing / Boost, Boost / Timing, Temps / RPM / Boost, Fuel & Ignition,
Engine Health, and Driver Inputs presets keep related signals together. Invalid
oil pressure, injector duty, and knock samples appear as gaps instead of zero.

UPDATE FIRMWARE
---------------
1. Connect MackoDash to the Windows PC with its update USB cable.
2. Keep the dashboard powered for the entire update.
3. Open MackoDash Utility and choose Update Firmware.
4. Select Download Latest to fetch and validate the newest official release,
  or use Choose ZIP with MackoDash-Firmware.zip from any older GitHub release.
5. Confirm the dashboard COM port.
6. Select Install Firmware and wait for verification to finish.

The update replaces the ESP32-P4 bootloader, partition table, OTA metadata,
application, and onboard SPIFFS. It preserves NVS settings, odometer data,
SD-card themes, and ESP32-C6 firmware.

Do not unplug USB or power during an update. If the port is busy, close serial
monitors and other flashing programs, then retry.

USB FILE TRANSFER
-----------------
The USB update cable transfers files through the MackoDash Utility; the SD card
does not appear as a Windows drive. Keep a working SD card inserted in the
dashboard. Stop active drive recording before downloading logs or sending a
theme or boot logo. Downloads and uploads are CRC-verified before completion.

DASHBOARD QUICK CONTROLS
------------------------
- Tap Settings to open the complete menu.
- Hold Settings to choose Day, Dim, or Night brightness.
- Open Settings > System > Shortcuts & Tips for the complete on-device control guide.
- Configure automatic recording and log filename types under Settings > Logs > Driving Logs.
- Configure whole-bar shift stages, colors, brightness, and redline flashing
  under Settings > Engine Limits.
- Select English, Spanish, Portuguese, or Japanese under Settings > Display.
- Configure Hondata Analog 0-6 fuel input and measured empty/full voltages under
  Settings > System > Fuel Gauge Setup. Follow the on-device wiring instructions,
  disconnect the sender from any stock-cluster power feed, and never allow more
  than 5 V to reach a Hondata analog input.
- Open Settings > System > Contact & Support for problem reporting, email,
  social, and feedback QR codes.
- Critical engine warnings appear in a compact banner without covering gauges.
- Simulation is hidden by default and can be enabled under Display for setup.
